# bcorQPFS

This repository contains the supplementary R code for the bcorQPFS paper.

## Contents

- `simulation/`: code for the simulation studies.
- `realdata/`: code for the ADNI real-data analysis.

See the `README.md` file in each folder for details and instructions.

The ADNI data are not included in this repository. Researchers must obtain authorized access through the [ADNI website](https://adni.loni.usc.edu/).
